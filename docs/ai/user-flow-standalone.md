# 서버 없이 유저 플로우 보기

[독립형 유저 플로우](user-flow-standalone.html)를 내려받거나 파일 탐색기에서 열면 브라우저에서 바로 볼 수 있다. 로컬 서버, API 서버, 외부 글꼴 및 별도 파일이 필요하지 않다. 팀원에게 이 HTML 파일을 전달해도 같은 화면을 열 수 있다.

기존 검토 화면의 사용자 행동·조건별 흐름·새 아이디어, 검색·상태 필터·아코디언·조건 링크를 제공한다. 앱의 공통 헤더는 포함하지 않는다. 근거 파일 링크는 GitHub로 연결되므로 해당 링크를 열 때는 인터넷 접속이 필요하다. 네트워크 없이 보는 경우 글꼴은 기기에 설치된 대체 글꼴을 사용한다.

## Claude 공유

[Claude에서 유저 플로우 보기](https://claude.ai/artifact/PabSzbfZRoFqTEtXQfzDtb). 링크가 있는 사람은 Claude 계정 없이 볼 수 있으며, 공유 설정에서 공개 범위를 변경할 수 있다. 공개 링크로만 접근한 사람은 아티팩트에 댓글을 남길 수 없다. 이 아티팩트도 별도로 올린 스냅샷이므로 원본을 수정한 뒤에는 다시 게시해야 같은 링크에 변경 사항이 반영된다.

## 기준과 갱신

이 파일은 2026-10-28 전체 검토 결과에 이후 일부 수정 사항을 반영한 **스냅샷**이다. 행동 105개, 조건 17개, 새 아이디어 6개를 포함한다. 원본 화면이나 데이터가 바뀌어도 기존 HTML 또는 별도로 공유한 아티팩트에는 자동으로 반영되지 않는다. 대부분의 근거 링크는 기존 검토 커밋 `ecd372668b06c788d5dba4b92c1e285e8a23ded4`에 고정하며, 프로필 재시도 근거는 2026-11-07 수정 커밋 `f7dffd591507e76cfa88853836673aea998191bb`에 고정한다. 구현 상태는 프론트 코드 분석 기준이며 실제 서버 동작 확인과 구분한다.

Node와 의존성이 준비된 저장소에서 최신 원본으로 다시 만들려면 다음을 실행한다.

```sh
npm ci
node scripts/build-user-flow-standalone.mjs
```

생성기는 `src/widgets/user-flows/ui/user-flow-page.tsx`와 그 데이터, `src/shared/ui/button.tsx`, 앱 공통 스타일을 사용해 이 폴더의 `user-flow-standalone.html`을 덮어쓴다. 원본의 외부 Pretendard 웹폰트 선언만 제외하고 CSS와 JavaScript를 모두 파일 안에 넣는다. 실제 포함된 패키지의 라이선스 파일과 저작권 헤더도 HTML의 `third-party-licenses` 블록에 보존한다. `@radix-ui/react-compose-refs`는 npm 배포본에 라이선스 파일이 없어 같은 저장소의 `@radix-ui/react-slot`에 포함된 WorkOS 공통 MIT 원문을 사용한다. 다른 패키지의 고지를 찾지 못하면 생성을 중단한다.

다른 컴포넌트에 유틸리티 클래스를 추가하거나 컴포넌트를 분리하면 생성기의 Tailwind `@source` 범위도 함께 확인한다. `.env`나 API 데이터를 읽지 않는다. 다시 만든 뒤 팀에 전달한 파일이나 Claude 아티팩트도 별도로 갱신해야 한다.

## 검증

2026-10-28 KST, Node 24.22.1에서 동일한 소스로 두 번 생성한 파일의 SHA-256이 같았고, 원본 폴더와 짧은 검증 복사본의 결과도 같았다. 당시 HTML은 371,347바이트이며 SHA-256은 `6B52324EF8B3F600FB3DC519E969DD59053D95492F5A664326FE09D92367F451`이었다. 실제 번들 모듈과 CSS 및 번들러 런타임에 해당하는 13개 패키지의 고지를 확인했다.

Chromium에서 `file://`로 열고 외부 요청을 차단하여 다음을 확인했다.

- 360px·1440px 폭에서 가로 넘침 없이 화면을 표시한다.
- 105개 행동·17개 조건·6개 아이디어와 사용자가 제거한 안내 문구의 부재를 확인했다.
- 검색, 빈 결과·초기화, 구현 상태 및 영역 필터가 동작한다.
- 조건 링크 왕복, 초점 이동, 새로고침·뒤로·앞으로가 동작한다.
- 탭 방향키와 Home·End 조작이 동작한다.
- 화면 로딩 중 실행 오류와 외부 네트워크 요청은 발생하지 않았다.

검증 로그와 화면 캡처는 Git 비추적 `build/user-flow-offline-check.json`, `build/user-flow-offline-360.png`, `build/user-flow-offline-1440.png`에 있다. 이는 정적 화면 검증이며 실제 백엔드·로그인·메일·AI·권한 성공 검증은 아니다.

### 2026-11-02 — 최신 main 통합

PR #25에서 최신 공통 CSS와 shadcn 4.23.0을 반영해 두 번 재생성했으며 결과 해시가 같았다. 당시 HTML은 **372,249바이트**, SHA-256은 `3455265722801034C00FBC167159E0479DA9658BE7D7DD04FD3831BAC934CE7C`였다. 목록과 근거 커밋은 기존 2026-10-28 검토 스냅샷을 유지했다.

Node 24.22.1과 Chromium에서 `file://`로 열고 외부 요청을 차단해 360·1440px에서 재검사했다. 105개 행동·17개 조건·6개 아이디어, 검색 없음·초기화, 상태·영역 필터, 조건 왕복·초점·주소 복원과 키보드 조작이 통과했다. 가로 넘침·페이지 실행 오류·외부 요청이 없었다. 검증용 체크아웃의 `build/flow-smoke.json`, `build/flow-smoke-360.png`, `build/flow-smoke-1440.png`에 기록했다. 별도로 공유한 Claude 아티팩트는 자동 갱신되지 않는다.

### 2026-11-07 — 프로필 재시도 수정 반영

프로필 생성 성공 후 추가 저장 실패 시 같은 화면에서 수정 요청만 다시 보내도록 바뀐 내용을 반영했다. 생성 성공 응답이 유실된 경우의 서버 상태와 `userId`·학년 계약은 계속 확인이 필요하다. 두 번 생성한 결과의 해시가 같았고 현재 HTML은 **372,520바이트**, SHA-256은 `59F97ACA9156A204287C5779E8F8D32882B6B650816C8BA2998CD993A40C69AC`다. 별도로 공유한 Claude 아티팩트에는 자동 반영되지 않는다.
