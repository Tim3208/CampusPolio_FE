CampusPolio 1차 UI/UX 시안

스케치에서 확정한 화면 흐름(홈, 탐색, 상세, 마이페이지)에 Figma 팔레트와 공통 디자인 기준을 입힌 도색 단계 시안입니다. 사진은 picsum 예시 이미지이고, 프로젝트 제목과 이름, 숫자는 길이 확인용 예시입니다.

디자인 기준 헤더 홈 탐색 상세 마이페이지
데스크톱 프레임

디자인 기준

대상 화면 전체에 같은 색, 글자 크기, 모양, 상태 규칙을 씁니다. 강조색은 main-10 하나로 고정하고, 나머지는 남색 계열 중립색으로 위계를 만듭니다.

글자 (Pretendard)

상세 제목 42프로젝트 제목
페이지 제목 36프로젝트 모음
섹션 제목 28주요 프로젝트
카드 제목 17카드 제목은 2줄까지
본문 16.5상세 본문은 줄간격 1.85
메타 13작성자, 조회, 좋아요

모바일 본문은 15.5~16px, 제목은 한국어 단어가 끊기지 않게 줄바꿈합니다.

모양과 상태

주요 행동보조 행동텍스트 버튼
비활성키보드 포커스
선택된 칩칩공학 태그보조 태그
프로젝트 검색그리드리스트

버튼·입력 10px, 카드·패널 14px, 칩·태그·검색창은 둥근 pill. 비활성은 회색 바탕과 흐린 글자, 포커스는 main-10 외곽선(어두운 면에서는 main-20)으로 표시합니다. 모바일 주요 버튼은 높이 44~48px.

화면 폭 규칙

1280px 이상
탐색 카드 3열. 나머지는 1024px 규칙과 같음
1024~1279px
탐색·마이페이지 왼쪽 사이드바 유지, 탐색·마이페이지 카드 2열, 홈 카드 3열, 상세는 본문과 자료 2단
768~1023px
사이드바 대신 상단 메뉴(마이페이지)와 필터 버튼(탐색), 카드 2열, 상세는 1단이고 자료는 본문 아래 2칸, 헤더 검색창 유지
767px 이하
헤더 검색은 버튼, 로그인 버튼 하나, 카드 1열, 태그 필터는 하단 시트, 마이페이지 메뉴는 2열 링크
